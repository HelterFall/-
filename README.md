# ДВОР — зимняя ночь

Небольшая атмосферная 3D-игра от первого лица на Godot 4.7.

## Что внутри

- Ночной зимний двор между советскими панельными домами.
- Детская площадка: качели, горка и снег вокруг.
- Процедурное ночное небо со звёздами, холодный высотный туман и мягкое свечение фонарей.
- Шейдеры снежного покрытия и панельного бетона с вариациями шероховатости и загрязнения.
- Детализированные оконные рамы, внутреннее освещение квартир, шторы, отливы и балконы; повторяющиеся детали фасадов собраны через MultiMesh.
- Объёмная модель заснеженного седана с отдельными стёклами, дисками, зимним протектором и хромированными деталями.
- Процедурные шейдеры потёртого металла, ржавчины, мокрого льда и слякоти.
- Ходьба от первого лица: WASD и мышь на компьютере.
- Сенсорный джойстик и свайпы для поворота камеры на Android.
- Сцена собирается из процедурных 3D-моделей и шейдеров, внешние ассеты не нужны.
- Два Android-профиля: Compatibility для более широкого списка устройств и Mobile (Vulkan) для телефонов с поддержкой Vulkan.
- Процедурные PBR-шейдеры добавляют микрорельеф и вариации шероховатости бетона, асфальта, снега и наледи.

## Скачать APK

После каждого push в `main` GitHub Actions собирает две Android-версии:

- **Dvor-Android-Compatibility** — основной вариант для более старых и широкого круга Android-устройств (OpenGL ES).
- **Dvor-Android-Mobile** — отдельный вариант для современных устройств с Vulkan. Для Mobile Godot указывает Android 9.0 и Vulkan 1.0 как минимальную платформу и графический API; Compatibility поддерживает Android 7.0 и OpenGL ES 3.0.

Обе версии имеют разные package ID, поэтому их можно установить одновременно и сравнить.

1. Открой вкладку **Actions** в репозитории.
2. Выбери последний успешный запуск **Build Android APK**.
3. Внизу страницы скачай нужный артефакт.
4. Распакуй ZIP и установи APK на Android.

Также сборку можно запустить вручную через **Actions → Build Android APK → Run workflow**.

## Запуск в Godot

Открой папку проекта в Godot 4.7 или новее и запусти `main.tscn`.
