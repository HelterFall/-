# ДВОР — зимняя ночь

Небольшая атмосферная 3D-игра от первого лица на Godot 4.7.

## Что внутри

- Ночной зимний двор между советскими панельными домами.
- Детская площадка: качели, горка и снег вокруг.
- Процедурное ночное небо со звёздами, холодный высотный туман и мягкое свечение фонарей.
- Шейдеры снежного покрытия и панельного бетона с вариациями шероховатости и загрязнения.
- Детализированные оконные рамы, отливы и балконы; повторяющиеся детали фасадов собраны через MultiMesh.
- Ходьба от первого лица: WASD и мышь на компьютере.
- Сенсорный джойстик и свайпы для поворота камеры на Android.
- Сцена собирается из процедурных 3D-моделей и шейдеров, внешние ассеты не нужны.
- Рендер оставлен на Compatibility для широкой Android-совместимости; включены умеренные SSAO, glow и MSAA.

## Скачать APK

После каждого push в `main` GitHub Actions собирает Android APK.

1. Открой вкладку **Actions** в репозитории.
2. Выбери последний успешный запуск **Build Android APK**.
3. Внизу страницы скачай артефакт **Dvor-Android-APK**.
4. Распакуй ZIP и установи `Dvor.apk` на Android.

Также сборку можно запустить вручную через **Actions → Build Android APK → Run workflow**.

## Запуск в Godot

Открой папку проекта в Godot 4.7 или новее и запусти `main.tscn`.
